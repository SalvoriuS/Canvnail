# Canvnail · editor local

Editor de textos, imágenes y dibujos por capas y páginas, con eliminación gratuita de fondo y exportación PNG/JPG/PDF en el navegador. No necesita cuentas, claves API ni servicios de procesamiento externos.

## Instalación y arranque

Requisitos: **Node.js 24 LTS** (incluye npm) y un navegador de escritorio actual. Se recomienda Chrome o Edge para el portapapeles y el selector de carpeta. Funciona en Windows, macOS y Linux; el acceso directo `.cmd` es exclusivo de Windows. Comic Sans MS debe estar instalada en el sistema; si falta se usa una fuente alternativa.

Descarga el código y abre una terminal en la carpeta que contiene `package.json`. Con nvm puedes seleccionar Node 24 (`nvm install 24` y `nvm use 24`). Después ejecuta:

```sh
npm ci
npm run setup:background
npm start
```

Abre **http://127.0.0.1:4173**. Para detener el servidor, pulsa Ctrl+C en la terminal. En instalaciones ya preparadas basta con `npm start` o, en Windows, `Iniciar-Canvnail.cmd`. No abras `index.html` directamente.

La instalación necesita Internet para las dependencias y para descargar U2NETP (4,4 MiB) y U2NET completo (167,8 MiB). Los modelos se descargan desde versiones fijadas de rembg y se verifican con SHA-256 antes de instalarlos. No se incluyen en Git. Si la descarga falla, vuelve a ejecutar `npm run setup:background`. El resto del editor puede usarse sin los modelos; quitar fondo requiere completar su instalación. Después de prepararlo, el procesamiento funciona sin Internet: los recursos se sirven desde este equipo y las imágenes se procesan en un Web Worker local.

## Privacidad, guardado y distribución

- El servidor solo escucha en `127.0.0.1`. Esta aplicación está preparada para uso local; no es un servicio multiusuario preparado para exponerlo a Internet.
- No hay cuentas, telemetría ni subidas de imágenes a un servidor externo. El contenido del portapapeles se lee al pegar, según los permisos del navegador.
- El autoguardado usa IndexedDB en el perfil del navegador. Puede perderse si borras sus datos o cambias de navegador, perfil o dirección/puerto. Usa **Guardar proyecto** para conservar copias `.canvnail.json` con las imágenes originales y los retoques.
- Publicar el código no publica IndexedDB. Los proyectos descargados sí contienen tus imágenes y textos: no los añadas al repositorio. `.gitignore` excluye proyectos, resultados de pruebas, dependencias, modelos, registros y archivos de entorno.
- El repositorio debe empezar en esta carpeta, junto a `package.json`. Los perfiles de navegador, capturas, descargas e investigaciones de otras carpetas no forman parte de Canvnail.
- El código propio y la ilustración de prueba usan **MIT**, con atribución al alias SalvoriuS. Consulta `LICENSE` y `THIRD_PARTY_NOTICES.md` para los componentes externos. `private: true` en `package.json` evita publicar por accidente en npm; no determina la visibilidad del repositorio de GitHub.
- Los modelos U2NET/U2NETP tienen licencia Apache-2.0 confirmada por su autor, independiente de la MIT del editor. El autor también reserva la cuestión de los derechos de los datos de entrenamiento DUTS. La revisión y sus fuentes están en `THIRD_PARTY_NOTICES.md`; no se distribuye el conjunto de datos.

Antes de compartir cambios, ejecuta `npm run check:publication` en el repositorio local. Revisa tanto archivos nuevos como preparados para un commit y comprueba que el autor utiliza correo privado de GitHub. Es una ayuda preventiva: revisa también los archivos que decidas compartir. La configuración del autor es local a Git y no se transfiere al clonar.

## Disponible

### Organización de la interfaz

- Izquierda: **Añadir** reúne texto, subida y pegado de imágenes. **Dibujar** muestra sus herramientas, color, grosor y la capa de destino. Las capas tienen su propia zona y permanecen accesibles sin quedar desplazadas por las herramientas. El borrador de dibujo solo se activa si hay una capa de dibujo visible y desbloqueada seleccionada; para borrar una foto se usa Fondo en sus propiedades.
- Derecha: las propiedades cambian según la selección. Texto tiene **Texto / Efectos / Posición**; una imagen, **Ajustes / Fondo / Posición**; un dibujo, **Dibujo / Ajustes / Posición**. Las pestañas conservan los valores y permiten navegación con flechas del teclado. Cambiar a Posición cierra el pincel para poder mover y transformar con normalidad.
- La transparencia del fondo pertenece a **Página**, accesible desde la fila Página de la izquierda o desde la indicación bajo Exportar. Ya no se mezcla con los ajustes de una imagen. La cabecera indica página actual o todas las páginas, y distingue fondo transparente, fondo de la página o formato sin transparencia.
- **Guardar proyecto** conserva el archivo editable; **Exportar** genera el resultado final. **Nuevo proyecto** nombra correctamente la acción que inicia otro documento, mientras **Limpiar** vacía solo la página actual. La barra inferior reserva las acciones de páginas y muestra **Añadir página** con texto, no solo un signo.
- **Atajos** abre una ayuda breve. **Escape** o **Terminar retoque** permite volver a seleccionar. Abrir Añadir durante el dibujo también termina ese modo. En móvil, lienzo, herramientas/capas y propiedades se ordenan verticalmente a ancho completo, en lugar de mostrar dos paneles estrechos.
- Un clic izquierdo en el espacio vacío alrededor de la página deselecciona elementos y grupos y vuelve a mostrar las propiedades de Página. Si estabas dibujando o retocando, también sale de ese modo y conserva los cambios. No modifica el documento ni añade una operación de deshacer. Los controles, las propiedades, los tiradores, las barras de desplazamiento y el clic derecho conservan la selección.
- Se conservan la identidad visual de Canvnail, los proyectos anteriores y todas las funciones. La reorganización utiliza `workspace.css` para separar la estructura del espacio de trabajo de los estilos originales.

### Herramientas y funciones

- Lienzo inicial 1280 × 720, formato vertical 1080 × 1920 y dimensiones personalizadas entre 64 y 8192 px por lado.
- Páginas independientes: la barra bajo el lienzo permite cambiar de página, añadir una del mismo tamaño o elegir otro formato, duplicar y eliminar. La última página no se puede eliminar. Estas operaciones tienen deshacer/rehacer; el contenido y las capas de cada página se mantienen separados. Los proyectos admiten hasta 100 páginas, 500 elementos por página y 5000 por proyecto.
- Formato **A4 · folio vertical** y **A4 · folio horizontal**, a 2480 × 3508 px o 3508 × 2480 px (300 ppp). El PDF conserva las medidas físicas exactas de 210 × 297 mm o 297 × 210 mm. Las guías de margen de 20 mm no se exportan. Al añadir texto en A4, se usa Arial de unos 12 puntos impresos, sin contorno ni fondo y dentro de los márgenes. Se trabaja con cajas de texto y páginas añadidas manualmente; no hay flujo ni paginación automática como en Word.
- Exportación: el selector junto al botón principal ofrece **PNG**, **JPG** y **PDF**. PNG y JPG exportan la página activa; el nombre añade su número si hay varias. PNG conserva el alfa; JPG usa calidad 95 % y rellena de blanco las transparencias. PDF reúne todas las páginas en su orden, respeta los distintos tamaños y usa fondo blanco para las zonas transparentes. Las páginas se rasterizan para conservar efectos, filtros, tipografías y dibujos; el texto del PDF no es seleccionable. Para editar, conserva el proyecto `.canvnail.json`.
- Destino de guardado: en Chrome compatible, las exportaciones y el guardado del proyecto abren Guardar como y solicitan Descargas como carpeta inicial. Puedes elegir otra carpeta y nombre; el navegador decide la ubicación final y puede recordar preferencias. Si esa API no está disponible o el navegador integrado la bloquea, se usa la descarga habitual y su configuración de destino. Cancelar el diálogo no altera el proyecto ni genera una descarga alternativa.
- Texto con Comic Sans MS por defecto, fuentes del sistema, ajuste de líneas, color, alineación, negrita y cursiva.
- Edición directa: haz doble clic en un texto para escribir sobre el propio lienzo, también si está girado o forma parte de un grupo. Conserva tipografía, contorno, fondo y alineación, y sincroniza el campo del panel lateral. Enter añade una línea; **Terminar edición**, Ctrl/Cmd+Enter o un clic fuera confirma los cambios; Escape cancela la sesión de edición. Cada sesión confirmada se deshace como una sola operación, y los cambios se autoguardan y se incluyen al guardar/exportar. Dentro del cuadro funcionan la selección de texto y el deshacer nativo. Los textos bloqueados no se pueden editar.
- Contorno y fondo independientes y combinables, padding horizontal/vertical y esquinas redondeadas.
- Arrastre, coordenadas numéricas, laterales para ajustar la caja y esquinas para escalar texto y efectos.
- Giro de imágenes, textos y capas de dibujo alrededor de su centro: arrastra el tirador redondo conectado al borde superior o indica **Ángulo de giro** en las propiedades. Se admiten ángulos de −360 a +360 grados y décimas de grado; Shift durante el arrastre ajusta a saltos de 15°. Cada arrastre se deshace como una sola operación; Escape cancela el giro en curso. Las capas bloqueadas no se pueden girar. El ángulo se conserva en el proyecto, en PNG/JPG/PDF y en el PNG individual de una imagen (cuyo tamaño se amplía para incluir el giro). Los proyectos anteriores se abren sin giro.
- Tras girar, los tiradores de tamaño trabajan en los ejes del elemento y mantienen el anclaje opuesto. El imán usa los límites visibles del elemento girado. Los pinceles de restauración, borrado y dibujo siguen actuando sobre sus píxeles originales aunque la capa esté girada.
- Subida de varias imágenes y pegado desde el portapapeles con Ctrl+V o el botón Pegar imagen. El botón puede pedir permiso al navegador; Ctrl+V es la alternativa si se deniega.
- Las imágenes se mueven y redimensionan con ocho tiradores, con proporción bloqueable, controles numéricos y botón para encajarlas en el lienzo.
- Quitar fondo: selecciona una imagen y pulsa **Quitar fondo**. Hay indicación de progreso y cancelación. Se conserva el original en el proyecto y puedes usar **Restaurar original completo** o Deshacer. La imagen mantiene sus dimensiones y posición. Repetir el recorte parte del original para evitar acumular pérdidas.
- Calidad del recorte: **Rápido** usa el modelo ligero y **Mayor calidad** usa U²-Net completo. Elegir un modo no modifica el recorte hasta pulsar Quitar fondo. La elección y el modo del último resultado se guardan por imagen. Mayor calidad consume más memoria y tiempo; no garantiza una mejora en todas las imágenes. El resultado aplicado aparece debajo del botón y puede cancelarse durante el proceso. El cambio de modelo libera la sesión anterior.
- **Afinar bordes** aparece tras recortar o retocar una imagen. Está plegado para dejar espacio a las herramientas habituales. **Contraer / expandir** (−8 a +8 px) permite quitar halos o recuperar el contorno; **Suavizar** (0–8 px) difumina la transición; **Definir borde** (0–100 %) aumenta el contraste del alfa. Las distancias se refieren a píxeles de la imagen original. Ajusta los controles y pulsa **Aplicar bordes** para ver el resultado; **Restablecer bordes** recupera exactamente la base conservada. Cada aplicación/restablecimiento se puede deshacer, conserva la transparencia previa y se guarda con sus parámetros y base editable en el proyecto. No requiere ejecutar otra vez la IA. Al usar un pincel se fija el acabado actual como punto de partida para los retoques siguientes; afinar después conservará esos retoques. Repetir Quitar fondo parte del original y sustituye el recorte, sus bordes y sus retoques.
- Restauración manual: después de quitar el fondo, pulsa **Restaurar con pincel**, ajusta el grosor entre 1 y 500 píxeles de la imagen original y pinta mediante clic o arrastre. Solo se recupera el original en las zonas pintadas, conservando su transparencia previa. **Terminar retoque** sale del modo pincel. Cada trazo se puede deshacer/rehacer; Escape cancela un trazo en curso y sale del pincel sin perder los anteriores. Los retoques y el original se conservan en el autoguardado y en el proyecto descargado, y el resultado se incluye al exportar PNG.
- Borrado manual: **Borrar con pincel** vuelve transparentes las zonas pintadas, con grosor ajustable entre 1 y 500 píxeles y deshacer/rehacer por trazo. Está disponible también antes de quitar el fondo automáticamente; conserva el original para poder restaurarlo después. Puedes alternar entre borrado y restauración sin perder los retoques.
- Salir del retoque: el botón **Terminar retoque** permanece visible encima del lienzo. También puedes pulsar Escape, volver a pulsar el pincel activo, hacer clic fuera de la imagen o seleccionar una capa. Al salir, reaparecen los tiradores y puedes mover y redimensionar de nuevo. Para cancelar el quitafondos automático durante el cálculo, pulsa **Cancelar** o Escape.
- Filtros y ajustes: selecciona una imagen y usa **Filtros y ajustes** en el panel derecho. Incluye Original, Blanco y negro, Sepia y Negativo, combinables con brillo, contraste y saturación entre 0 y 200 % (100 % es el valor neutro). Cada control tiene deslizador y entrada numérica sincronizados. Un arrastre completo del deslizador se deshace como una sola operación; **Restablecer filtros y ajustes** también se puede deshacer. Los ajustes se guardan como propiedades editables, sin modificar los píxeles ni los retoques del fondo. Se ven en el lienzo, las miniaturas y los pinceles, y se incluyen tanto en Exportar PNG como en Descargar esta imagen PNG. Los proyectos antiguos se abren con ajustes neutros.
- Dibujo: el panel izquierdo ofrece **Pincel**, **Borrador**, **Cubo de relleno**, **Línea**, **Flecha**, **Rectángulo** y **Círculo**, con color y grosor entre 1 y 200 píxeles de la capa. **Rellenar formas** añade relleno a rectángulos y elipses. Arrastra para pintar o trazar; Shift restringe a cuadrados, círculos o líneas a 45 grados. El cubo rellena la zona conectada del color pulsado en la capa de dibujo, con una pequeña tolerancia para bordes suavizados.
- Si seleccionas una herramienta sin tener una capa de dibujo seleccionada, se crea una transparente a tamaño del lienzo. **Nueva capa de dibujo** permite separar partes del diseño. Selecciona una capa de dibujo y pulsa una herramienta para continuar pintando en ella, incluso después de guardarla y reabrirla. El borrador y el cubo no modifican fotos ni textos de otras capas. Cada trazo, forma o relleno se deshace como una operación; Escape cancela el trazo en curso y sale del dibujo. **Terminar retoque**, pulsar de nuevo la herramienta o hacer clic fuera de la capa también permite salir. Puedes mover, redimensionar, duplicar, ordenar, ocultar y bloquear toda la capa.
- Los dibujos se guardan localmente como capas PNG con transparencia dentro del proyecto; trazos y formas quedan rasterizados en su capa. Usa capas separadas si quieres mover una forma independientemente. Se exportan con la composición y también mediante Descargar esta imagen PNG. El dibujo admite lienzos de hasta 32 millones de píxeles.
- **Descargar esta imagen PNG**, en Ajustes, guarda solo la capa seleccionada con su transparencia. Para exportar toda la composición con alfa, abre **Página**, activa **Lienzo transparente** y usa Exportar PNG. Las capas que cubran el fondo siguen apareciendo en la composición; el damero es solo una ayuda visual y no se exporta.
- Capas: selección, orden mediante botones o arrastre, visibilidad y bloqueo.
- Selección múltiple: Shift/Ctrl/Cmd + clic en el lienzo o en el panel de capas añade o quita elementos. También puedes arrastrar un rectángulo desde una zona vacía; los elementos ocultos o bloqueados no se añaden directamente con el rectángulo. El panel derecho muestra la selección y permite moverla o escalarla con coordenadas y tamaño numérico. Las cuatro esquinas escalan proporcionalmente posiciones, tamaños, tipografías, contornos y fondos, conservando los giros individuales. El imán y las flechas también actúan sobre el conjunto.
- Grupos: pulsa **Agrupar** o Ctrl+G; **Desagrupar** o Ctrl+Shift+G los separa. Un clic en cualquier miembro selecciona el grupo completo y un doble clic permite editar ese miembro individualmente. Los grupos se guardan por página sin rasterizar los elementos; cada miembro sigue visible en el panel de capas con la indicación Grupo. No hay grupos anidados: agrupar selecciones que contienen grupos los combina en uno. Duplicar un grupo crea otro independiente, y mover/redimensionar/agrupar/desagrupar/borrar se puede deshacer. Si un miembro está oculto o bloqueado, se debe mostrar y desbloquear antes de transformar todo el conjunto. Las selecciones temporales se limpian al cambiar de página; la relación de grupo permanece en el proyecto.
- Ajuste magnético suave al mover textos e imágenes: bordes y centro del lienzo, guías rosas y tolerancia de 6 píxeles de pantalla independiente del zoom. Alt desactiva el ajuste temporalmente; el botón Imán permite desactivarlo por completo. Las flechas y los campos numéricos mantienen la colocación exacta sin imán.
- Deshacer/rehacer, duplicación, borrado y zoom.
- **Limpiar lienzo**: el botón de papelera junto a Deshacer/Rehacer borra todos los elementos de la página actual, incluidos los ocultos y bloqueados. Conserva tamaño, fondo y transparencia de la página, y no toca otras páginas. Sale de los pinceles, cancela el procesamiento o la carga pendiente de imágenes y se puede deshacer con un solo Ctrl+Z.
- Guardado automático en IndexedDB y guardado/apertura de proyectos `.canvnail.json` con todas las páginas e imágenes incluidas. El formato de proyecto 3 migra los archivos anteriores de una sola página sin perder sus elementos, recortes, bordes ni filtros.

El guardado automático depende del navegador y de esta dirección. Conserva una copia descargada del proyecto antes de limpiar los datos del navegador. Comic Sans MS usa la instalación local; las fuentes no se incluyen en el proyecto ni se descargan.

La versión 0.2 importa los proyectos de texto de Trazo, tanto desde archivos `.trazo.json` como desde su antiguo autoguardado en localStorage. El proyecto actual pasa a IndexedDB y el autoguardado antiguo se conserva. Los nombres personalizados se respetan; el nombre predeterminado es Canvnail.

PNG, JPG, WebP, GIF, BMP y AVIF se decodifican localmente e incorporan como PNG o JPG. La transparencia se conserva en PNG; los formatos animados se incorporan como una imagen estática. No se cargan imágenes mediante URLs externas. Límites: 25 MB por archivo original, 32 millones de píxeles por imagen y 100 MB por proyecto importado.

El recorte utiliza U²-Net pequeño o completo para detección del objeto principal. Los fondos complejos, objetos poco destacados, transparencias y pelo fino pueden dejar restos o perder detalle; revisa el resultado antes de exportar y usa los ajustes de borde y los pinceles para afinarlo. Ambos modelos usan una máscara de 320 × 320 reescalada a la resolución original, conservan los colores originales y multiplican el alfa previo por la máscara. El modo completo aumenta la capacidad del modelo, no la resolución de entrada. Licencias y procedencia: `THIRD_PARTY_NOTICES.md`.

## Atajos

T: añadir texto; Ctrl+V: pegar imagen; Supr: eliminar; flechas: mover 1 px; Shift + flechas: mover 10 px; Alt durante el movimiento: sin imán; Shift al redimensionar una imagen: invertir temporalmente el bloqueo de proporción; Ctrl+D: duplicar; Ctrl+Z / Ctrl+Shift+Z: deshacer/rehacer; Ctrl+S: descargar proyecto; Escape: cancelar un arrastre o deseleccionar. El pegado de texto en los campos conserva el comportamiento del navegador.

## Validación

```sh
npm test
npm run setup:browser
npm run test:browser
```

`npm test` ejecuta las pruebas internas sin navegador. Playwright es una dependencia de desarrollo fijada en el archivo de bloqueo; `setup:browser` descarga su Chromium independiente. En Linux puede hacer falta `npx playwright install --with-deps chromium` para instalar las bibliotecas del sistema. No se necesita REA ni una instalación personal de Chrome.

`test:browser` inicia un servidor temporal en un puerto libre y ejecuta las suites por separado, con perfiles nuevos que no contienen tus sesiones ni proyectos. Detiene el servidor al terminar y guarda los resultados locales en `tests/artifacts/` (excluido de Git). Requiere los modelos preparados para las pruebas del quitafondos. Para ejecutar solo una suite: `npm run test:browser -- ux-browser.cjs`. Las suites no necesitan resultados de ejecuciones anteriores. El pegado se prueba con eventos y respuestas Clipboard controlados, sin alterar el portapapeles del sistema.

Las comprobaciones automáticas de GitHub ejecutan las pruebas internas y de navegador en Linux. Esta configuración se incluye en el código; solo se ejecutará allí cuando publiques el repositorio.

`npm run test:browser -- background-browser.cjs` ejecuta el modelo real sobre una ilustración original del proyecto y verifica primer plano/fondo en el canal alfa, resolución, descarga PNG independiente, transparencia del lienzo, guardado/reapertura, restauración del original, deshacer/rehacer y cancelación. Bloquea direcciones externas y confirma que todas las peticiones del proceso permanecen en localhost. Los resultados y la medición local se guardan en `tests/artifacts/background-result.json`. No es una medición de precisión sobre fotografías reales.

`npm run test:browser -- restore-browser.cjs` comprueba la restauración por zonas, el grosor sobre imágenes deformadas, trazos continuos con zoom, deshacer/rehacer por trazo, cancelación, exportación PNG durante el retoque, guardado/reapertura y bloqueo de capas. `npm test` también verifica la mezcla de color y alfa del pincel y que las zonas no pintadas permanecen intactas.

`npm run test:browser -- erase-browser.cjs` verifica borrado por zonas con distintos grosores, continuidad, deshacer/rehacer, alternancia con restauración, las formas de salir del retoque, movimiento y redimensionado tras salir, cancelación de un trazo, transparencia del PNG y persistencia de los cambios y del original.

`npm run test:browser -- adjustments-browser.cjs` comprueba filtros y ajustes, sincronización de controles, deshacer/rehacer por gesto, restablecimiento, colores y alfa en ambos PNG, retoque con ajustes activos, guardado/reapertura y capas bloqueadas. `npm test` cubre además la migración de proyectos antiguos y el rechazo de ajustes o filtros no válidos.

`npm run test:browser -- drawing-browser.cjs` comprueba las siete herramientas, relleno conectado, color/grosor, formas rellenas y restricciones con Shift, deshacer/rehacer por gesto, cancelación, salida y transformación de capas, pintura tras redimensionar, PNG transparente durante el dibujo, capas mixtas, visibilidad/bloqueo, autoguardado y reapertura editable. `npm test` también verifica regiones del cubo, colores de sustitución cercanos y compatibilidad de las capas de dibujo con proyectos antiguos.

`npm run test:browser -- quality-browser.cjs` ejecuta los dos modelos reales, verifica transparencia/primer plano, cambio y liberación de sesiones, cancelación y peticiones exclusivamente locales. Guarda tiempos y métricas en `tests/artifacts/quality-result.json`. Una ejecución de referencia en este equipo tardó unos 2,3 s en Rápido y 5,5 s en Mayor calidad; son medidas de una imagen concreta, no una garantía de rendimiento o precisión.

`npm run test:browser -- edges-browser.cjs` verifica contraer/expandir, suavizar/definir, controles con aplicación explícita, base sin degradación acumulada, deshacer/rehacer, restablecimiento exacto, transparencia PNG, parámetros/base al guardar y reabrir, y compatibilidad con pinceles. Confirma que afinar no carga modelos ni utiliza servicios externos. `npm test` compara la morfología optimizada con una referencia y comprueba los límites y la migración de los nuevos campos.

`npm run test:browser -- pages-export-browser.cjs` comprueba PNG con alfa, JPG con fondo blanco, PDF real de tres páginas y tamaños A4, solicitud de destino en Descargas, tipos de archivo y cancelación mediante dobles del selector nativo. También verifica aislamiento de páginas, duplicación/borrado/deshacer, formato de escritura A4, migración/guardado/reapertura del proyecto completo y diseño móvil. El PDF de prueba se renderiza con PDFium para revisar visualmente todas sus páginas. Las demás pruebas usan explícitamente la descarga alternativa para evitar diálogos nativos en Chrome sin interfaz. `npm test` verifica además el esquema de páginas, los identificadores y los tamaños físicos del PDF.

`npm run test:browser -- rotation-browser.cjs` verifica giro numérico y por arrastre de textos, imágenes y dibujos, saltos de 15°, deshacer/rehacer/Escape, anclajes al redimensionar, pinceles sobre capas giradas, PNG/PDF e imagen individual, bloqueo y persistencia. `npm test` comprueba las transformaciones inversas, límites girados, conservación del anclaje de los ocho tiradores y migración/validación de ángulos.

`npm run test:browser -- groups-browser.cjs` verifica selección aditiva y por rectángulo, agrupación/desagrupación, movimiento y escala conjuntos, campos numéricos y flechas, deshacer/rehacer/Escape, conservación de giros y efectos de texto, bloqueo/visibilidad, duplicación y borrado atómicos, y persistencia al guardar/reabrir. `npm test` comprueba expansión de grupos, escalado de centros y efectos y límites de transformación sin perder distancias relativas.

`npm run test:browser -- ux-browser.cjs` comprueba la organización contextual, las capas disponibles mientras se dibuja, conservación de valores entre pestañas, salida segura de los modos, navegación por teclado y ayuda, alcance de exportación, transparencia solo en Página y ausencia de desbordamiento en escritorio, portátil y móvil. Las pruebas de regresión acceden a las propiedades mediante las mismas pestañas que utiliza una persona.

`npm run test:browser -- deselect-browser.cjs` verifica deselección fuera de la página para selección individual, múltiple y grupos, salida del dibujo, conservación del documento y del historial, y que propiedades, zoom y clic derecho mantengan la selección.

`npm run test:browser -- inline-text-browser.cjs` comprueba doble clic, texto girado y agrupado, edición multilínea en directo, sincronización lateral y foco, confirmación por botón/Ctrl+Enter/cambio de capa o pestaña, cancelación, deshacer/rehacer, bloqueo, deselección exterior y persistencia en exportación y guardado/reapertura.
